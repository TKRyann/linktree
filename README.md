# 🔗 Freelancer Link Page

Uma página de links moderna e totalmente personalizável, desenvolvida como projeto freelancer para centralizar redes sociais, contatos e outros links importantes em um único lugar.

O projeto foi criado com foco em desempenho, responsividade e facilidade de personalização, oferecendo uma alternativa mais flexível ao Linktree.

---

## 📖 Sobre o projeto

Esta aplicação permite reunir diversos links em uma única página, facilitando o compartilhamento de redes sociais, portfólios, sites, lojas e outras plataformas.

O layout foi desenvolvido para proporcionar uma boa experiência tanto em dispositivos móveis quanto em computadores, com um design limpo e intuitivo.
